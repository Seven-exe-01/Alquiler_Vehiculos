# Sistema de Alquiler de Vehículos - Programación II - Espinosa Giuliana - Gonzalez Julieta - Gonzalez Alexis

Trabajo integrador de las Unidades 1 y 2.

## Estructura del proyecto

- `enums.py`: enumeraciones para `TipoVehiculo`, `EstadoVehiculo` y `EstadoReserva`
- `clientes.py`: clase `Cliente` con encapsulamiento, propiedades y validación de DNI
- `sucursales.py`: clase `Sucursal` y control de sucursales y vehículos
- `vehiculos.py`: clase `Vehiculo` y subclases (`Auto`, `Camioneta`, `Moto`) con cálculo de costo según tipo y días
- `main.py`: menú interactivo por consola para gestionar sucursales, clientes, vehículos y reservas.
